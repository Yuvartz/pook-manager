# pook manager

תחנת פליטות בדפדפן. 100 צלילים מסונתזים + 24 פליצות אמיתיות, 12 מקצבים, יישור לביט והקלטת לולאה.

כל הצלילים המסונתזים — גם הפליצות וגם התופים — מיוצרים בזמן אמת ב-Web Audio API, אז הם
שוקלים אפס ועובדים אופליין, וכל לחיצה נשמעת קצת שונה מהקודמת. בנוסף יש טאב **"אמיתי"** עם
24 הקלטות אמיתיות שנחתכו, נוקו ועברו סינון כפילויות (ראה `public/farts/`).

## מה יש בפנים

**100 יחידות ב-12 משפחות** — קלאסי, בראפ, צייצן, באס, רצף, רטוב, טונאלי, אוויר, אקזוטי,
הדהוד, בוס, מלודי. כל יחידה היא סט פרמטרים למנוע סינתזה אחד: מתנד סאו-טות' עם רטט (LFO)
שנותן את המרקם, רעש חום או לבן מסונן לאוויר, waveshaper לדיסטורשן, מסנן low-pass עם מעטפת,
ובחלק מהמשפחות גם שער אמפליטודה (sputter) או השהיה עם משוב (echo).

**12 מקצבים** מסונתזים חיים — בום באפ, טראפ, האוס, טכנו, רגאטון, דראם אנד באס, פאנק, רוק,
מזרחי, לו-פיי, דיסקו, מטרונום. כל תוף (בעיטה, סנר, מחיאה, היי-האט, פרקשן) נבנה מגלים ורעש.
טווח קצב: 60–180 BPM.

**יישור לביט** — לחיצה נדחית לצעד הבא בגריד, כך שהפליצה נוחתת בזמן.

**הקלטת לולאה** — 16 צעדים, עד 32 לחיצות. מה שמקליטים חוזר בכל סבב, עם סימון צבעוני על הגריד.

**מלודי** — 8 יחידות מכוונות לסולם A מינור פנטטוני (A2–D4), לניגון קו בס.

**טאב "אמיתי"** — 24 פליצות אמיתיות מתוך הקלטות שנחתכו אוטומטית לפי שקט, קוצצו בקצוות,
סוננו לפי דמיון ספקטרלי (כדי שלא יהיו שתיים דומות) וקודדו ל-mp3. הן מתנגנות בלחיצה בדיוק כמו
היחידות המסונתזות — כולל יישור לביט והקלטה ללולאה.

## הרצה מקומית

```bash
npm install
npm run dev
```

## build

```bash
npm run build     # יוצר dist/
npm run preview   # בדיקה של ה-build
```

## פריסה ל-GitHub Pages

הפרויקט כולל workflow ב-`.github/workflows/deploy.yml` שבונה ומפרסם בכל push ל-`main`.
כדי להפעיל: בריפו ב-GitHub → **Settings → Pages → Source: GitHub Actions**.
ה-`base: "./"` ב-`vite.config.js` דואג שהנתיבים יעבדו גם מתחת ל-subpath.

| `רווח` | נגן / עצור |

## הערות

- הדפדפן חוסם אודיו עד לאינטראקציה ראשונה של המשתמש, לכן ה-`AudioContext` נוצר ומופעל
  בלחיצה הראשונה. עד אז הנורית בכותרת מציגה "ממתין".
- באייפון צריך לכבות את מתג ההשתקה הפיזי.
- אין שמירה מקומית של לולאות — הן קיימות רק בזיכרון הדף.
