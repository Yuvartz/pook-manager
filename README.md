# pook manager

תחנת פליטות בדפדפן. 24 פליצות אמיתיות, 12 מקצבים, מקלדת סולמות, יישור לביט והקלטת לולאה.

כל הפליצות הן הקלטות אמיתיות שנחתכו, נוקו ועברו סינון כפילויות (`public/farts/`).
התופים והמקצבים עדיין מסונתזים חיים ב-Web Audio API.

## מה יש בפנים

**24 פליצות אמיתיות** — מתוך הקלטות גולמיות שפוצלו אוטומטית לפי שקט, קוצצו בקצוות,
סוננו לפי דמיון ספקטרלי (log-mel + מעטפת) כדי שלא יהיו שתיים דומות, וקודדו ל-mp3 מונו.
מחולקות ל-6 קבוצות טמבר: קלאסי, בראפ, בהיר, עמוק, באס ורטוב.

**12 מקצבים** מסונתזים חיים — בום באפ, טראפ, האוס, טכנו, רגאטון, דראם אנד באס, פאנק, רוק,
מזרחי, לו-פיי, דיסקו, מטרונום. כל תוף (בעיטה, סנר, מחיאה, היי-האט, פרקשן) נבנה מגלים ורעש.
טווח קצב: 60–180 BPM.

**פסנתר** — מקלדת אמיתית (7 לבנים + 5 שחורים + אוקטבה) שמנגנת פליצה בגובה משתנה
(`playbackRate`), כך שאפשר לנגן מלודיות. הפליצה שנבחרה בלוח היא זו שנכנסת לפסנתר.
בורר הסולם (מז'ור, מינור, פנטטוני, בלוז, דוריאן, מזרחי) מדגיש את הקלידים ששייכים לסולם —
כל הקלידים נשארים נגישים, הסולם הוא מדריך ויזואלי ולא נעילה. אייקוני הסולמות הם מדבקות
של אפרסק-טוסיק שנוצרו עם gpt-image-1 (`scripts/generate-scale-icons.mjs`, דורש
`OPENAI_API_KEY`), אחד לכל מצב-רוח: שמש, ירח, במבוק, סקסופון, עלה וגמל.

**יישור לביט** — לחיצה נדחית לצעד הבא בגריד, כך שהפליצה נוחתת בזמן.

**הקלטת לולאה** — 16 צעדים, עד 32 לחיצות. מה שמקליטים חוזר בכל סבב, עם סימון צבעוני על הגריד.
תווים מהמקלדת נשמרים עם הגובה שלהם. (זה לופר של אירועים — סמפלר-סטייל — לא הקלטת אודיו.)

**הקלטת קול** 🎤 — מקליטים מהמיקרופון (עד 8 שניות, עד 6 קולות) וההקלטה הופכת לפד רגיל:
אפשר לירות אותה בלחיצה, להקליט אותה ללולאה, ואפילו לבחור אותה ככלי של הפסנתר — לשיר תו
אחד ולנגן איתו מלודיות.

**הקלטת שיר** ⬇ — לוכדת את כל מה שנשמע (פליצות + תופים + קולות) ומורידה קובץ `pook-jam.wav`
(סטריאו 16-bit). לוחצים, מנגנים, לוחצים שוב — הקובץ יורד.

## הרצה מקומית

```bash
npm install
npm run dev
```

## build

```bash
npm run build     # יוצר dist/
npm run preview   # בדיקה של ה-build
```

## פריסה ל-GitHub Pages

הפרויקט כולל workflow ב-`.github/workflows/deploy.yml` שבונה ומפרסם בכל push ל-`main`.
כדי להפעיל: בריפו ב-GitHub → **Settings → Pages → Source: GitHub Actions**.
ה-`base: "./"` ב-`vite.config.js` דואג שהנתיבים יעבדו גם מתחת ל-subpath.

## מקלדת

| מקש | פעולה |
| --- | --- |
| `1`–`9` | הפעלת פליצות 1–9 |
| `0` | נאד בהפתעה |
| `A`–`K` | קלידים לבנים |
| `W` `E` `T` `Y` `U` | קלידים שחורים |
| `רווח` | נגן / עצור |

## הערות

- הדפדפן חוסם אודיו עד לאינטראקציה ראשונה של המשתמש, לכן ה-`AudioContext` נוצר ומופעל
  בלחיצה הראשונה. עד אז הנורית בכותרת מציגה "ממתין".
- באייפון צריך לכבות את מתג ההשתקה הפיזי.
- אין שמירה מקומית של לולאות — הן קיימות רק בזיכרון הדף.
